Plugins

A plugin is a file that adds custom weapon types, armor types, shield types, mods and races. Plugins are kept on this device and apply to every profile. Adding, removing or switching one reloads the page. Items saved with a plugin's type stay in your profile and work again when the plugin is on. The Plugin builder makes plugin files with forms, no file editing needed.

      Purchasable passives

      Passives are always active. A level costs more the higher you already are, and every level is bought on top of the previous ones.

      Fighting styles

      A fighting style is a passive that unlocks a whole set of actions. A character can own only one. Its actions appear in a sub-tab of the Actions tab. Levels are bought on top of the previous ones.
